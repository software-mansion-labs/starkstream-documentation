# Starkstream Documentation

This repository contains the documentation for the Starkstream platform.

The [official documentation](https://starkstream.io/docs) is periodically
rebuilt by combining the documentation from the following repositories:

 - [`software-mansion-labs/starkstream-documentation`](https://github.com/software-mansion-labs/starkstream-documentation): this
   repository. Documentation about the Apibara platform and hosted service.
 - [`software-mansion-labs/starkstream-dna`](https://github.com/software-mansion-labs/starkstream-dna): documentation about
   integrations, the Direct Node Access (DNA) protocol, and self-hosting.
 - [`software-mansion-labs/starkstream-typescript-sdk`](https://github.com/software-mansion-labs/starkstream-typescript-sdk):
   documentation for the Typescript SDK.

## Contributing

If you spot any issue with our documentation, or simply want to improve it,
feel free to contribute to it!

**Fixing issues**

 - Fork and clone the repository
 - Make your changes
 - Open a PR with the fix
 - Done!

**Adding new pages and sections**

 - Join [our Telegram](https://t.me/starkstream) and get in touch with the
   team to discuss your ideas. This is to optimize your contribution for maximum
   impact.
 - Fork and clone the repository
 - Make your changes
 - Open a PR
 - Done!
