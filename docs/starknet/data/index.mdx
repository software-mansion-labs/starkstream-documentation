# Starknet data reference

This page contains reference about the available data in Starknet DNA streams.
Import these types from `@apibara/starknet`. The definitions below omit
`readonly` modifiers for readability.

### Related pages

- [Starknet data filter reference](/docs/starknet/filter)

## Filter ID

All filters have an associated ID. To help clients correlate filters with data,
the filter ID is included in the `filterIds` field of all data objects.
This field contains the list of _all filter IDs_ that matched a piece of data.

## Nullable fields

Fields marked with `?` can be absent.

## Field elements

Starkstream represents Starknet field elements as hex-encode strings.

```ts
export type FieldElement = `0x${string}`;
```

## Data types

### Block

The root object is the `Block`.

```ts
export type Block = {
  header: BlockHeader;
  transactions: Transaction[];
  receipts: TransactionReceipt[];
  events: Event[];
  messages: MessageToL1[];
  traces: TransactionTrace[];
  storageDiffs: StorageDiff[];
  contractChanges: ContractChange[];
  nonceUpdates: NonceUpdate[];
};
```

### Block header

This is the block header, which contains information about the block.

```ts
export type BlockHeader = {
  blockHash?: FieldElement;
  parentBlockHash: FieldElement;
  blockNumber: bigint;
  sequencerAddress: FieldElement;
  newRoot?: FieldElement;
  timestamp: Date;
  starknetVersion: string;
  l1GasPrice: ResourcePrice;
  l1DataGasPrice: ResourcePrice;
  l2GasPrice?: ResourcePrice;
  l1DataAvailabilityMode: "blob" | "calldata" | "unknown";
};

export type ResourcePrice = {
  priceInFri?: FieldElement;
  priceInWei?: FieldElement;
};
```

**Properties**

- `blockHash`: the block hash.
- `parentBlockHash`: the block hash of the parent block.
- `blockNumber`: the block number.
- `sequencerAddress`: the sequencer address.
- `newRoot`: the new state root.
- `timestamp`: the block timestamp.
- `starknetVersion`: the Starknet version.
- `l1GasPrice`: the L1 gas price.
- `l1DataGasPrice`: the L1 data gas price.
- `l2GasPrice`: the L2 gas price, when available.
- `l1DataAvailabilityMode`: the L1 data availability mode.

- `priceInFri`: the price of L1 gas in the block, in units of fri (10^-18 $STRK).
- `priceInWei`: the price of L1 gas in the block, in units of wei (10^-18 $ETH).

### Event

An event is emitted by a transaction.

```ts
export type Event = {
  filterIds: number[];
  address: FieldElement;
  keys: FieldElement[];
  data: FieldElement[];
  eventIndex: number;
  eventIndexInTransaction: number;
  transactionIndex: number;
  transactionHash: FieldElement;
  transactionStatus: "succeeded" | "reverted" | "unknown";
};
```

**Properties**

- `address`: the address of the contract that emitted the event.
- `keys`: the keys of the event.
- `data`: the data of the event.
- `eventIndex`: the index of the event in the block.
- `eventIndexInTransaction`: the index of the event in its transaction.
- `transactionIndex`: the index of the transaction that emitted the event.
- `transactionHash`: the hash of the transaction that emitted the event.
- `transactionStatus`: the status of the transaction that emitted the event.

**Relevant filters**

- `filter.events`
- `filter.transactions[].includeEvents`
- `filter.events[].includeSiblings`
- `filter.messages[].includeEvents`

### Transaction

Starknet has different types of transactions, all of them are grouped together
in the `Transaction` type. Common transaction information is accessible in the
`meta` field.

```ts
export type TransactionMeta = {
  transactionIndex: number;
  transactionHash: FieldElement;
  transactionStatus: "succeeded" | "reverted" | "unknown";
};

export type Transaction = {
  filterIds: number[];
  meta: TransactionMeta;
  transaction:
    | { _tag: "invokeV0"; invokeV0: InvokeTransactionV0 }
    | { _tag: "invokeV1"; invokeV1: InvokeTransactionV1 }
    | { _tag: "invokeV3"; invokeV3: InvokeTransactionV3 }
    | { _tag: "l1Handler"; l1Handler: L1HandlerTransaction }
    | { _tag: "deploy"; deploy: DeployTransaction }
    | { _tag: "declareV0"; declareV0: DeclareTransactionV0 }
    | { _tag: "declareV1"; declareV1: DeclareTransactionV1 }
    | { _tag: "declareV2"; declareV2: DeclareTransactionV2 }
    | { _tag: "declareV3"; declareV3: DeclareTransactionV3 }
    | { _tag: "deployAccountV1"; deployAccountV1: DeployAccountTransactionV1 }
    | { _tag: "deployAccountV3"; deployAccountV3: DeployAccountTransactionV3 };
};
```

**Properties**

- `meta`: transaction metadata.
- `transaction`: the transaction type.

- `meta.transactionIndex`: the index of the transaction in the block.
- `meta.transactionHash`: the hash of the transaction.
- `meta.transactionStatus`: the status of the transaction.

**Relevant filters**

- `filter.transactions`
- `filter.events[].includeTransaction`
- `filter.messages[].includeTransaction`

### Transaction receipt

The receipt of a transaction contains information about the execution of the transaction.

```ts
export type TransactionReceipt = {
  filterIds: number[];
  meta: TransactionReceiptMeta;
  receipt:
    | { _tag: "invoke"; invoke: InvokeTransactionReceipt }
    | { _tag: "l1Handler"; l1Handler: L1HandlerTransactionReceipt }
    | { _tag: "declare"; declare: DeclareTransactionReceipt }
    | { _tag: "deploy"; deploy: DeployTransactionReceipt }
    | { _tag: "deployAccount"; deployAccount: DeployAccountTransactionReceipt };
};

export type TransactionReceiptMeta = {
  transactionIndex: number;
  transactionHash: FieldElement;
  actualFee: FeePayment;
  executionResources: ExecutionResources;
  executionResult:
    | { _tag: "succeeded"; succeeded: ExecutionSucceeded }
    | { _tag: "reverted"; reverted: ExecutionReverted };
};

export type InvokeTransactionReceipt = {};

export type L1HandlerTransactionReceipt = {
  messageHash: Uint8Array;
};

export type DeclareTransactionReceipt = {};

export type DeployTransactionReceipt = {
  contractAddress: FieldElement;
};

export type DeployAccountTransactionReceipt = {
  contractAddress: FieldElement;
};

export type ExecutionSucceeded = {};

export type ExecutionReverted = {
  reason?: string;
};

export type FeePayment = {
  amount: FieldElement;
  unit: "wei" | "fri" | "unknown";
};

export type ExecutionResources = {
  computation: ComputationResources;
  dataAvailability: DataAvailabilityResources;
};

export type ComputationResources = {
  steps: bigint;
  memoryHoles?: bigint;
  rangeCheckBuiltinApplications?: bigint;
  pedersenBuiltinApplications?: bigint;
  poseidonBuiltinApplications?: bigint;
  ecOpBuiltinApplications?: bigint;
  ecdsaBuiltinApplications?: bigint;
  bitwiseBuiltinApplications?: bigint;
  keccakBuiltinApplications?: bigint;
  segmentArenaBuiltin?: bigint;
};

export type DataAvailabilityResources = {
  l1Gas: bigint;
  l1DataGas: bigint;
};
```

**Relevant filters**

- `filter.transactions[].includeReceipt`
- `filter.events[].includeReceipt`
- `filter.messages[].includeReceipt`

### Transaction trace

The trace of a transaction contains the function calls executed by the
transaction. Like transactions, traces are grouped in the `TransactionTrace`
type and the trace root depends on the transaction type.

```ts
export type TransactionTrace = {
  filterIds: number[];
  transactionIndex: number;
  transactionHash: FieldElement;
  traceRoot:
    | { _tag: "invoke"; invoke: InvokeTransactionTrace }
    | { _tag: "declare"; declare: DeclareTransactionTrace }
    | { _tag: "deployAccount"; deployAccount: DeployAccountTransactionTrace }
    | { _tag: "l1Handler"; l1Handler: L1HandlerTransactionTrace };
};

export type InvokeTransactionTrace = {
  validateInvocation?: FunctionInvocation;
  executeInvocation:
    | { _tag: "success"; success: FunctionInvocation }
    | { _tag: "reverted"; reverted: { reason?: string } };
  feeTransferInvocation?: FunctionInvocation;
};

export type DeclareTransactionTrace = {
  validateInvocation?: FunctionInvocation;
  feeTransferInvocation?: FunctionInvocation;
};

export type DeployAccountTransactionTrace = {
  validateInvocation?: FunctionInvocation;
  constructorInvocation?: FunctionInvocation;
  feeTransferInvocation?: FunctionInvocation;
};

export type L1HandlerTransactionTrace = {
  functionInvocation?: FunctionInvocation;
};

export type FunctionInvocation = {
  contractAddress: FieldElement;
  entryPointSelector: FieldElement;
  calldata: FieldElement[];
  callerAddress: FieldElement;
  classHash: FieldElement;
  callType: "libraryCall" | "call" | "delegate" | "unknown";
  result: FieldElement[];
  calls: FunctionInvocation[];
  events: number[];
  messages: number[];
};
```

**Properties**

- `traceRoot`: the trace root, one variant per transaction type.
- `validateInvocation`, `executeInvocation`, `feeTransferInvocation`: the `__validate__`, `__execute__`, and fee transfer calls. `executeInvocation` is either the invocation or the revert reason.
- `callType`: how the function was called.
- `events`, `messages`: the indices, within the transaction, of the events emitted and messages sent by the call.

Traces are only returned when the server ingests them, see the
[Starknet filter reference](/docs/starknet/filter#transactions).

**Relevant filters**

- `filter.transactions[].includeTrace`
- `filter.events[].includeTransactionTrace`
- `filter.messages[].includeTransactionTrace`

### Storage diff

A storage diff is a change to the storage of a contract.

```ts
export type StorageDiff = {
  filterIds: number[];
  contractAddress: FieldElement;
  storageEntries: StorageEntry[];
};

export type StorageEntry = {
  key: FieldElement;
  value: FieldElement;
};
```

**Properties**

- `contractAddress`: the contract whose storage changed.
- `storageEntries`: the storage entries that changed.

- `key`: the key of the storage entry that changed.
- `value`: the new value of the storage entry that changed.

**Relevant filters**

- `filter.storageDiffs`
