# Installation

Create an indexer that streams events from the STRK staking contract on Starknet
Mainnet. You will need Node.js and a package manager; this guide uses `pnpm`.

The TypeScript SDK is still published as `apibara` and `@apibara/*`. Its CLI,
configuration file, and generated types keep those names during the Starkstream
migration, so use the commands and imports below as written.

## Stream access

The hosted stream requires an API token. [Request one from the Starkstream team
on Telegram](https://t.me/starkstream), then export it in the terminal where you
run the indexer:

```bash [Terminal]
export DNA_TOKEN="YOUR_API_TOKEN"
```

The SDK reads `DNA_TOKEN` automatically. Existing API keys continue to work.
See [Starknet stream access](/docs/networks/starknet#authentication) for details,
including self-hosted servers.

## Create the project

Initialize a TypeScript project without an indexer, then install its dependencies:

```bash [Terminal]
mkdir my-indexer
cd my-indexer
pnpm dlx apibara@next init . --language=ts --no-create-indexer
pnpm install
```

If pnpm reports ignored dependency build scripts, use
[`pnpm approve-builds`](https://pnpm.io/cli/approve-builds) to review them, then
rerun `pnpm install`.

Create the indexer with explicit chain, network, and storage options:

```bash [Terminal]
pnpm apibara add strk-staking --chain=starknet --network=mainnet --storage=none --dnaUrl=https://mainnet.starkstream.io
pnpm install
```

The CLI creates `indexers/strk-staking.indexer.ts`, adds the Starknet package,
and registers `strkStaking` in `apibara.config.ts`. It also generates
`package.json` scripts and a `tsconfig.json`; keep the generated compiler settings.

## Configure the indexer

Replace `apibara.config.ts` with this configuration. The starting block limits
historical indexing to the period relevant to the staking contract.

```ts [apibara.config.ts]
import { defineConfig } from "apibara/config";

export default defineConfig({
  runtimeConfig: {
    strkStaking: {
      startingBlock: 900_000,
      streamUrl: "https://mainnet.starkstream.io",
      contractAddress:
        "0x028d709c875c0ceac3dce7065bec5328186dc89fe254527084d1689910954b0a",
    },
  },
});
```

Replace `indexers/strk-staking.indexer.ts` with:

```ts [indexers/strk-staking.indexer.ts]
import { StarknetStream } from "@apibara/starknet";
import { defineIndexer } from "apibara/indexer";
import { useLogger } from "apibara/plugins";
import type { ApibaraRuntimeConfig } from "apibara/types";

export default function (runtimeConfig: ApibaraRuntimeConfig) {
  const { startingBlock, streamUrl, contractAddress } = runtimeConfig.strkStaking;

  return defineIndexer(StarknetStream)({
    streamUrl,
    startingBlock: BigInt(startingBlock),
    finality: "accepted",
    filter: {
      events: [{ address: contractAddress as `0x${string}` }],
    },
    async transform({ block }) {
      const logger = useLogger();
      logger.log(`Block number ${block.header.blockNumber}`);
      for (const event of block.events) {
        logger.log(`Event ${event.eventIndex} tx=${event.transactionHash}`);
      }
    },
  });
}
```

`StarknetStream` supplies the filter and block types. `startingBlock` is the
first block to index, `filter.events` selects the contract's events, and
`transform` handles each matching block. See the [indexer
reference](/docs/getting-started/indexers) for other options.

## Run the indexer

Generate types for the runtime configuration, check the code, and start
development mode:

```bash [Terminal]
pnpm run prepare
pnpm run typecheck
pnpm run dev --indexers=strk-staking
```

The indexer logs matching blocks and events, then follows live data. Development
mode reloads the indexer when files change. Without `--indexers`, it runs all
indexers in the project.

If the stream returns `Unauthenticated`, check that `DNA_TOKEN` is set to a valid
token in the same terminal.

## Production build

Build the project and select the indexer to run:

```bash [Terminal]
pnpm run build
pnpm run start --indexer=strk-staking
```

Production mode runs one indexer per process and does not reload on file changes.
Start separate processes if your project contains multiple indexers.
