# Starknet filter reference

Pass a `Filter` to your Starknet indexer to select data before it reaches your
application. Import the SDK type and use `satisfies Filter` to check examples
against your installed package.

See the [SDK filter codecs](https://github.com/software-mansion-labs/apibara-typescript-sdk/blob/main/packages/starknet/src/filter.ts)
for complete TypeScript definitions, the [server filter schema](https://github.com/software-mansion-labs/starkstream-dna/blob/main/protocol/proto/starknet/v2/filter.proto)
for wire types, and the [data reference](/docs/networks/starknet/data) for responses.

## Filter ID

Each item filter accepts an optional numeric `id`. Returned data contains
`filterIds`, the IDs of the filters that matched it. Assign distinct IDs when
you need to distinguish matches in your transform.

## Field elements

Addresses and selectors use the SDK's `FieldElement` type: a hex string of the
form `` `0x${string}` ``. Use [getSelector](/docs/networks/starknet/helpers#getselector)
to derive an event selector from its name.

## Filter types

### Root

The root filter contains any combination of the following fields:

| Field | SDK type | Selects |
| --- | --- | --- |
| `header` | `HeaderFilter` | When to return block headers |
| `events` | `readonly EventFilter[]` | Contract events |
| `transactions` | `readonly TransactionFilter[]` | Transactions |
| `messages` | `readonly MessageToL1Filter[]` | Messages from Starknet to L1 |
| `storageDiffs` | `readonly StorageDiffFilter[]` | Contract storage changes |
| `contractChanges` | `readonly ContractChangeFilter[]` | Class declarations, replacements, and deployments |
| `nonceUpdates` | `readonly NonceUpdateFilter[]` | Contract nonce changes |

A standalone empty root filter (`{}`) cannot produce data and is rejected.
An empty item filter, such as `events: [{}]`, matches all items of that kind
subject to its default transaction-status filter.

### Header

| Value | Behavior |
| --- | --- |
| `always` | Return every block header, even when no body filter matches |
| `on_data` | Return the header when another filter matches; this is the default |
| `on_data_or_on_new_block` | Also return headers for new live blocks, even without a body match |

To receive only block headers:

```ts
import type { Filter } from "@apibara/starknet";

const filter = { header: "always" } satisfies Filter;
```

### Events

Use `EventFilter` to select events by emitting contract and keys. Conditions
within one item filter are combined; multiple item filters select the union
of their matches.

| Option | Behavior |
| --- | --- |
| `address` | Match the emitting contract; omit to match any contract |
| `keys` | Match keys by position, using `null` as a wildcard; the server indexes the first four positions |
| `strict` | Require exactly as many event keys as the filter specifies; otherwise use a prefix match |
| `transactionStatus` | `succeeded` (default), `reverted`, or `all` |
| `includeTransaction` | Include the emitting transaction |
| `includeReceipt` | Include that transaction's receipt |
| `includeMessages` | Include messages to L1 from the same transaction |
| `includeSiblings` | Include other events from the same transaction |
| `includeTransactionTrace` | Include that transaction's trace in `block.traces` |

Select transfers from the USDC contract used in the [SDK example](https://github.com/software-mansion-labs/apibara-typescript-sdk/blob/main/examples/cli-drizzle/indexers/2-starknet.indexer.ts) and include their receipts:

```ts
import { getSelector, type Filter } from "@apibara/starknet";

const filter = {
  events: [{
    id: 1,
    address: "0x053c91253bc9682c04929ca02ed00b3e423f6710d2ee7e0d5ebb06f3ecf368a8",
    keys: [getSelector("Transfer")],
    includeReceipt: true,
  }],
} satisfies Filter;
```

To match transfers from any contract, omit `address`. To match several contracts
or event names, add more entries to `events`.

For an event with a selector and two indexed addresses, match exactly three keys:

```ts
import { getSelector, type Filter } from "@apibara/starknet";

const filter = {
  events: [{ keys: [getSelector("Transfer"), null, null], strict: true }],
} satisfies Filter;
```

### Transactions

`TransactionFilter` supports:

| Option | Behavior |
| --- | --- |
| `transactionStatus` | `succeeded` (default), `reverted`, or `all` |
| `transactionType` | Match one transaction version using a tagged union |
| `includeReceipt` | Include its receipt |
| `includeMessages` | Include its messages to L1 |
| `includeEvents` | Include its events |
| `includeTrace` | Include its trace in `block.traces` |

Supported `transactionType._tag` values are `invokeV0`, `invokeV1`, `invokeV3`,
`declareV0`, `declareV1`, `declareV2`, `declareV3`, `deploy`, `deployAccountV1`,
`deployAccountV3`, and `l1Handler`. The matching payload property is an empty object.

Select account deployments with receipts:

```ts
import type { Filter } from "@apibara/starknet";

const filter = {
  transactions: [{
    transactionType: { _tag: "deployAccountV3", deployAccountV3: {} },
    includeReceipt: true,
  }],
} satisfies Filter;
```

To select all transactions, including reverted ones:

```ts
import type { Filter } from "@apibara/starknet";

const filter = { transactions: [{ transactionStatus: "all" }] } satisfies Filter;
```

### Messages

`MessageToL1Filter` selects messages sent **from Starknet to L1**.
For the opposite direction, select `l1Handler` transactions.

| Option | Behavior |
| --- | --- |
| `fromAddress` | Match the sender on Starknet; omit to match any sender |
| `toAddress` | Match the recipient on L1; omit to match any recipient |
| `transactionStatus` | `succeeded` (default), `reverted`, or `all` |
| `includeTransaction` | Include the sending transaction |
| `includeReceipt` | Include its receipt |
| `includeEvents` | Include its events |
| `includeTransactionTrace` | Include its trace in `block.traces` |

Trace include options require traces to have been ingested by the server. See
[transaction traces](/docs/networks/starknet/data#transaction-trace).

### Storage diff

`StorageDiffFilter` accepts `contractAddress`. Omit it to receive storage
changes for any contract.

### Contract change

`ContractChangeFilter.change` is a tagged union with one of these variants:

| Tag | Selects |
| --- | --- |
| `declaredClass` | Class declarations |
| `replacedClass` | Class replacements on existing contracts |
| `deployedContract` | Contract deployments |

Omit `change` to select all change types. For example, select deployments:

```ts
import type { Filter } from "@apibara/starknet";

const filter = {
  contractChanges: [{ change: { _tag: "deployedContract", deployedContract: {} } }],
} satisfies Filter;
```

### Nonce update

`NonceUpdateFilter` accepts `contractAddress`. Omit it to receive nonce updates
for any contract. Each state-change filter also accepts an optional `id`.
