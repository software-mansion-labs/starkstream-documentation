Starkstream provides Starknet DNA streams at the following URLs:

**Starknet Mainnet**

```txt
https://mainnet.starkstream.io/
```

**Starknet Sepolia**

```txt
https://testnet.starkstream.io/
```

Generate an API key at [starkstream.io](https://starkstream.io) and follow the
[setup guide](/docs/getting-started/installation#stream-access).

## Starknet appchains

You can ingest data from Starknet appchains and serve it using our open-source
DNA service. See the [Starkstream DNA repository](https://github.com/software-mansion-labs/starkstream-dna)
for server setup and development instructions.
