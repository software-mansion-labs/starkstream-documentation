## Authentication

The hosted Mainnet and Sepolia streams require an API token. To request one,
[contact the Starkstream team on Telegram](https://t.me/starkstream).
Existing API keys continue to work.

Export the token before starting your indexer:

```bash
export DNA_TOKEN="YOUR_API_TOKEN"
```

The TypeScript client reads this environment variable and sends the token in the
`Authorization: Bearer <token>` header. Self-hosted servers may use a different
authentication policy; follow the server operator's instructions.

## Starknet appchains

You can ingest data from Starknet appchains and serve it using our open-source
DNA service. Please get in touch with the team if you'd like a managed solution.
